## 路径

`process.cwd()`是指当前 node 命令执行时所在的文件夹目录
比如在 D:/aaa/bb 目录下执行 yarn build 那么 cwd 就是 D:/aaa/bb

`__dirname`是指被执行 js 文件所在的文件夹目录
比如 D:/aa/scripts
