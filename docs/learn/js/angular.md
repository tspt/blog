## 命令

```shell
// 创建项目
ng new [name]


--flat // 在当前项目的顶层创建新文件
--module xxx // 指定其声明模块

// 生成组件定义
ng generate component [name]
ng generate c [name]

// 生成指令定义，--flat默认为true
ng generate directive [name]
ng generate d [name]

// 生成NgModule定义
ng generate module [name]
ng generate m [name]

// 生成服务定义
ng generate service [name]
ng generate s [name]

// 生成接口定义
ng generate interface [name]
ng generate i [name]

// 生成管道定义
ng generate pipe [name]
ng generate p [name]
```
