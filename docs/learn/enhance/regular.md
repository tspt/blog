## 字符组

```text
\d   数字
\D   非数字
\w   [0-9a-zA-Z_]
\W   [^0-9a-zA-Z_]
\s   [\t\v\n\r\f]
\S   [^\t\v\n\r\f]
```

## 量词

```text
?   {0, 1}
+   {1,}
*   {0,}
{m}
{m,}
{m, n}
```

```text
??
+?
*?
{m,}?
{m, n}?
```

## \b

- \w 和\W 之间的位置
- ^与\w 之间的位置
- \w 与\$之间的位置

## \B

- \w 与\w 之间的位置
- \W 与\W 之间的位置
- ^与\W 之间的位置
- \W 与\$之间的位置

## 断言

- (?=p) 后面紧跟着 p 的位置
- (?!p) 后面不是紧跟着 p 的位置
- (?<=p) 前面紧跟着 p 的位置
- (?<!p) 前面不是紧跟着 p 的位置

## 例子

### 千分位

```js
"123456789".replace(/(?!^)(?=(\d{3})+$)/g, ".");
```
