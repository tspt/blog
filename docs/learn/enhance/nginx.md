## 正向代理 和 反向代理

给客户端做正向代理，给服务器做反向代理

## 均衡负载

分摊压力，将请求转发给服务器集群

配置负载均衡：

- 轮训： 默认方式
- weight： 权重分配
- ip_hash： ip 的 hash 结果分配
- fair： 响应时间分配和时间短优先分配

## 动静分离

高并发和静态资源缓存等特性，静态资源部署到 Nginx 上。

- 请求静态资源，去静态资源目录获取资源
- 请求动态资源，通过反向代理，将请求转发到后台应用去处理

配置动静分离：

一种方式：将静态资源独立成独立的域名，放在独立的服务器上；  
另一种方式：是动态和静态文件混合一起发布，通过 Nginx 配置区分。

## 集群（双机热备）
